# 装备系统序列帧扩展方案（精简版）

> 目标：在 **不改变现有架构** 的前提下，为武器和服装/头盔增加「按动画名可选的序列帧覆盖」，
> 统一遵循：**有配置就用序列帧，没有就回退到原有挂点/UV 行为**，并兼容「大部分是 4 向序列帧，但也可能只有单向序列帧」的情况。

---

## 1. 基础约定（保持现状）

- **角色主体**：
  - 继续使用 `CharacterFrameData` + `AnimationData` + `FrameData`：
    - 底层 spritesheet、`frameSize`、`framesPerRow`、`rowCount`。
    - 每帧包含部位像素/UV、武器锚点等。
  - 通过 `DualUVMapGenerator` 生成 BodyUVMap / HeadUVMap，供 Shader 采样。

- **装备基础显示（打底）**：
  - 武器（Weapon）：
    - 通过 `RenderWeapon` + `AnchorPoint` 用 `SpriteRenderer` 显示。
    - 使用单张或 4 向基础贴图（`GetSpriteByRow`）。
  - 服装 / 头盔（Clothing / Helmet）：
    - 通过 UVMap + 4 向基础贴图（`spriteSE/SW/NE/NW`）在 Shader 中渲染。
  - 以上行为在 **未配置序列帧** 时完全保持不变。

---

## 2. 统一行为模型

### 2.1 核心规则

对「任意一件装备 E，任意一个动画 A，任意一帧 (rowIndex, frameIndex)」：

1. 先获取当前动画名 `_currentAnimName = A`，当前方向 `_rowIndex`，当前帧 `_frameIndex`。
2. **查询：装备 E 是否为动画 A 配置了序列帧？**
   - 若未配置 → 直接使用 **原有挂点/UV 打底行为**。
   - 若已配置：
     - 再看「当前方向是否有 strip」：
       - 有 strip → 使用该 strip 的序列帧贴图。
       - 无 strip → 回退到原有挂点/UV 行为。

> 重点：不存在全局“模式枚举”。是否走序列帧，由「是否配置了序列帧 + 当前方向是否有 strip」自动决定。

### 2.2 4 向基础贴图的定位

- 4 向基础贴图 **永远只是打底**：
  - 武器：挂点模式下的默认贴图（Idle/Walk 等），或序列帧缺失时的回退贴图。
  - 服装/头盔：UV Map 采样的基础贴图，控制各方向光照/阴影差异。
- 「序列帧」是 **加号** 而不是 **替代整个系统**：
  - 有序列帧 → 优先用序列帧帧图。
  - 无序列帧 / 某方向缺失 → 回退到 4 向基础贴图对应的表现。

## 3. 概念数据结构

这里只描述概念，不要求立刻实现具体字段名。

```csharp
// 某件装备在某个动画下的一组序列帧配置
class EquipAnimSequence
{
    public string animationName;        // 如 "Idle" / "Walk" / "Attack" / "Die"
    public List<DirectionalStrip> strips; // 多个方向的 strip 集合
}

// 某一方向的一条时间轴
class DirectionalStrip
{
    public CharacterFacing facing;      // SE / SW / NE / NW
    public Sprite[] frames;             // 时间序列；长度可以为 1（静态）或 N（动画）
}

class EquipmentData : ScriptableObject
{
    public EquipmentType type;
    // ... 已有基础贴图字段 ...

    // 推荐：为武器与服装/头盔各保留一份列表（也可统一一份再用 type 区分）
    public List<EquipAnimSequence> weaponSequences;   // 仅 Weapon 使用
    public List<EquipAnimSequence> clothingSequences; // Clothing / Helmet 使用
}
```

特性：

- **4 向序列帧**：`strips` 中包含 4 条，facing = SE/SW/NE/NW。
- **单向序列帧**：`strips` 中只包含 1 条，例如 facing = SouthEast。
- 若对应方向找不到 strip，即视为「该方向没配置序列帧」。

## 4. 运行时查找序列帧（伪代码）

### 4.1 通用辅助函数

```csharp
Sprite TryGetSequenceSprite(EquipmentData equip,
                            string animName,
                            int rowIndex,
                            int frameIndex,
                            bool isWeapon)
{
    var list = isWeapon ? equip.weaponSequences : equip.clothingSequences;
    if (list == null) return null;

    // 1. 找动画名匹配的条目
    var seq = list.Find(s => string.Equals(s.animationName, animName,
                                           StringComparison.OrdinalIgnoreCase));
    if (seq == null || seq.strips == null || seq.strips.Count == 0) return null;

    // 2. 根据 rowIndex 得到当前朝向
    var facing = (CharacterFacing)rowIndex; // 0=SE, 1=SW, 2=NE, 3=NW

    // 3. 找对应方向 strip
    var strip = seq.strips.Find(x => x.facing == facing);
    if (strip == null || strip.frames == null || strip.frames.Length == 0)
        return null; // 没有该方向序列帧 → 回退

    // 4. 取帧：长度为 1 时视为静态图
    if (strip.frames.Length == 1)
        return strip.frames[0];

    int idx = frameIndex % strip.frames.Length; // 简单循环
    return strip.frames[idx];
}
```

### 4.2 武器逻辑（RenderWeapon 内部）

1. 先尝试序列帧：

```csharp

    //   仍可用 AnchorPoint 控制前后排序，以及必要偏移。
}
else
{

    // sr.sprite = equip.GetSpriteByRow(_rowIndex);

```

2. **单向序列帧行为**：
   - 若只给 SE 做了 Attack 序列帧：
     - 面向 SE → 能找到 strip，使用序列帧。
     - 面向 SW/NE/NW → 找不到 strip → 回退到挂点 + 4 向基础贴图。

### 4.3 服装 / 头盔逻辑（ApplyClothingToShader / ApplyHelmetToShader）

1. 计算当前部位的最终贴图方向（已考虑 `BodyPartRegion.spriteFacing`）：

```csharp
var facing = GetSpriteFacingForPart(CharacterBodyPart.Torso /* or Head */);
```

2. 先尝试序列帧，再回退基础贴图：

```csharp
var seqSprite = TryGetSequenceSprite(equip, _currentAnimName,
                                     (int)facing, _frameIndex,
                                     isWeapon: false);

Sprite finalSprite = seqSprite != null
    ? seqSprite                          // 序列帧贴图
    : equip.GetSprite(facing);           // 4 向基础贴图

if (finalSprite == null || finalSprite.texture == null)
{
    // 该动画 + 方向下完全无贴图 → 该装备在此方向不显示
    return;
}

// 把 finalSprite.texture + rect 传给 Shader，逻辑与当前实现一致
```

3. **单向序列帧行为**：
   - 例如斗篷只做了 SE 的 Attack strip：
     - Attack + 朝向 SE：使用序列帧斗篷。
     - Attack + 朝向 SW/NE/NW：回退到 UV 模式 + 4 向基础贴图（若该方向有基础图）。

## 5. 四向基础贴图与单向序列帧的协作总结

- **优先级**（同一装备、同一动画、同一方向）：
  1. 有序列帧 strip → 用序列帧。
  2. 无序列帧 strip → 武器回挂点，服装/头盔回 UV 模式 + 4 向基础贴图。
  3. 若基础贴图也缺失 → 该装备在此方向隐藏。

- **4 向基础贴图职责**：
  - 提供 **完整、稳定的默认表现**，确保「任何方向、任何动画」在不配序列帧时仍然可用。
  - 当只做了「部分方向的序列帧」时，仍然作为其它方向的回退逻辑。

- **单向序列帧的典型用途**：
  - 某些只在特定视角出现的演出（例如 UI、剧情、仅面向 SE 的攻击特写）。
  - 或在资源阶段先做一个方向的实验版，将来再补齐 4 向。

## 6. 实现顺序（简要建议）

1. 在 `EquipmentData` 中新增 `List<EquipAnimSequence>`（可区分 weapon/clothing）。
2. 在 `EquipmentRenderer` 中引入 `TryGetSequenceSprite`，按本方案改造：
   - `RenderWeapon` 先尝试序列帧，再回退挂点。
   - `ApplyClothingToShader` / `ApplyHelmetToShader` 先尝试序列帧，再回退基础 4 向贴图。
3. 用极少量测试资源验证：
   - Weapon：Attack 有 4 向序列帧；Idle 只有挂点基础图。
   - Weapon：Attack 只有 SE 单向序列帧，其他方向回退挂点。
   - Clothing：Walk 有 4 向序列帧；Idle 用 UV 模式基础图。
   - Clothing：Attack 只有 SE 单向序列帧，其它方向回退 UV。
